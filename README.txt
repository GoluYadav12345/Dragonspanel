# iRemoval Pro Registration Website

Open `index.html` in a browser to preview the site.

## Before publishing
1. Replace `YOUR_BINANCE_ADDRESS_HERE` in `index.html` with your verified payment address.
2. Never put a Binance private key, seed phrase, or API secret in the frontend.
3. This starter is a frontend demo: orders and TXIDs are not stored on a server.
4. For real order storage/payment verification, connect a secure backend/database and verify transactions server-side.
